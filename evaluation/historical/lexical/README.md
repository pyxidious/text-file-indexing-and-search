# Archivio storico della ground truth lessicale

Questi file sono conservati senza modifiche e si riferiscono alle query precedenti
in `queries.csv`: Q01 nome flow, Q02 nome pressure, Q06 contenuto flow.
`review.csv`, `proposed_positives.csv` e `proposed.json` sono proposte lessicali
storiche, non annotazioni semantiche e non metriche di una valutazione umana.
Non sono input della valutazione semantica corrente e non vanno rigenerati con
le nuove query. Gli eventuali vecchi output locali in `artifacts/` restano storici.
