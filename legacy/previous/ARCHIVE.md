# Archivio precedente al refactoring Homework 3

Questa directory conserva il codice precedente, i suoi test, configurazioni,
prompt e documentazione. Le pipeline con query/qrels ufficiali, confronto di
strategie e annotazione LLM sono escluse dal progetto corrente.

È un archivio storico, non un comando supportato dell'homework. I riferimenti
ai vecchi output e i risultati numerici nel suo README appartengono al vecchio
protocollo. Non usare questi giudizi per `evaluation/`.

Il corpus corrente è conservato in `../../corpus/documents/`; la nuova procedura
legge soltanto quei TXT e le dieci query originali preparate per l'homework.
